algorithm BFS(s₀, goal)
  input: start state s₀, goal test goal
  output: a path to a goal with the fewest steps, or failure
  Q ← ⟨s₀⟩                                     ▷ first in, first out
  SEEN ← {s₀}
  while Q ≠ ∅ do
    s ← pop-front(Q)
    if goal(s) then                            ▷ heuristic-search tests when a state is generated
      return path-to(s)
    for each (o, s′) in successors(s) do       ▷ every operator applicable in s
      if s′ ∉ SEEN then
        SEEN ← SEEN ∪ {s′}
        parent[s′] ← (s, o)
        push-back(Q, s′)
  return failure
